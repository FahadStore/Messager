# مرسال

رسائل خاصة مشفّرة بينك وبين أصدقائك عبر المعرّف — يعمل مباشرة على GitHub Pages.

## كيف يعمل
- عند التسجيل يُنشأ لك **معرّف** (مثل `7K2QM-9XAP4`) ومفتاح تشفير داخل متصفحك.
- شارك معرّفك أو رابط الدعوة، ويراسلك الآخرون بالخاص.
- كل رسالة **مشفّرة من طرف إلى طرف** (ECDH P-256 + AES-GCM)، وتُنقل عبر [ntfy.sh](https://ntfy.sh) الذي لا يرى إلا نصًا مشفّرًا.
- إشعارات القراءة: ✓ أُرسلت، ✓✓ وصلت، ✓✓ ملوّنة قُرئت.
- إرسال **الصور والفيديوهات فقط** (الفيديو حتى 15 ميغابايت): تُشفّر قبل الرفع، وتُضغط الصور الكبيرة تلقائيًا.
- **حساب تجريبي** («سالم») داخل جهازك فقط يرد عليك تلقائيًا لتجربة الموقع.
- تصميم للجوال أولًا، ناعم وبحركات سلسة، مع وضع داكن.
- **صورة شخصية** تُضغط لحجم صغير وتصل لجهات الاتصال تلقائيًا.
- **شارة توثيق** ✓ للمعرّفات الموثّقة (قائمة `VERIFIED` في `assets/app.js`).
- **كلمة مرور وتسجيل خروج**: يُشفَّر المفتاح بكلمة المرور (PBKDF2 + AES-GCM) ويُحفظ على الجهاز وعلى ntfy. الدخول من جهاز جديد يعمل إذا فُتح الحساب خلال آخر 12 ساعة؛ وللاحتفاظ الدائم انسخ المفتاح الاحتياطي.
- **حماية الوسائط**: الصور والفيديوهات المحمية لا تظهر عند المستلم إلا أثناء الضغط المطوّل، وعليها علامة مائية باسمه، ولا يمكن حفظها، وتختفي عند مغادرة الصفحة. (لا يستطيع أي موقع ويب منع لقطة الشاشة فعليًا.)
- المحادثات محفوظة على جهازك فقط. انسخ **المفتاح الاحتياطي** من الإعدادات لنقل حسابك لجهاز آخر.

## الملفات

- `assets/style.css` — التصميم
- `assets/app.js` — المنطق والتشفير
- `assets/logo.svg` — الشعار

## ملاحظات
- ntfy.sh يحتفظ بالرسائل 12 ساعة؛ إن لم تصل خلالها يعيد مرسال إرسالها تلقائيًا عند فتح الموقع.
- ntfy.sh يقبل مرفقات حتى 2 ميغابايت فقط (ومجموع 20 ميغابايت كل 3 ساعات)، لذلك يُقسَّم الملف المشفّر إلى أجزاء ويُجمَّع عند المستلم.
- ntfy.sh يحذف المرفقات بعد 3 ساعات؛ يحمّلها جهاز المستلم فور وصولها، وإن انتهت صلاحيتها يطلب من المرسل رفعها من جديد.
- البحث بالمعرّف يعمل إذا فتح صاحبه الموقع خلال آخر 12 ساعة؛ وإلا استخدم رابط الدعوة.
