# الدردشة العامة 💬

موقع دردشة عامة مباشرة: أي شخص يفتح الموقع يختار اسمًا ولونًا ويبدأ الكتابة، وتصل الرسائل لكل المتصلين فورًا.

## التشغيل

```bash
cd chat
npm start
```

ثم افتح `http://localhost:3000`.

## المميزات
- رسائل مباشرة عبر Server-Sent Events (بدون مكتبات خارجية، Node.js 18+ فقط).
- عدّاد المتصلين الآن.
- حفظ آخر 200 رسالة في `messages.json` لتظهر للزوار الجدد.
- حماية من الإغراق (8 رسائل كحد أقصى كل 10 ثوانٍ لكل IP) وحد 500 حرف للرسالة.
- واجهة عربية (RTL) متجاوبة مع الجوال، مع وضع ليلي.

## الإعدادات
- `PORT`: منفذ الخادم (الافتراضي 3000).
- `DATA_FILE`: مسار ملف حفظ الرسائل.

> ملاحظة: يحتاج الموقع إلى خادم Node.js (مثل Render أو Railway أو Fly.io)، ولا يعمل على GitHub Pages لأنها تستضيف الملفات الثابتة فقط.
